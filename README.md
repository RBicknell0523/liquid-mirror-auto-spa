# Liquid Mirror Auto Spa

Marketing site for Liquid Mirror Auto Spa LLC, a veteran-owned mobile auto detailing business — built with Next.js (App Router), React, and Tailwind CSS.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.

## Scripts

- `npm run dev` — start the development server
- `npm run build` — production build
- `npm start` — run the production build
- `npm run lint` — lint the codebase
- `npm test` — run the test suite (Vitest + React Testing Library)

## Project Structure

- `app/` — routes, global styles, and the branded favicon (`icon.tsx`)
- `components/` — page sections (`Hero`, `About`, `services/`, `contact/`) and shared UI primitives (`ui/`)
- `data/` — services, pricing, and contact info content

## Design Notes

Several values are intentional placeholders pending real content from the client: contact details (`data/contactInfo.ts`), the Hero tagline, and typography.
